# Dates d'examen

Site privé (connexion par e-mail + mot de passe) pour suivre les examens :
élève, accompagnateur, lieu, date, commentaire, paiements W, B et S.

Mise en route : voir [INSTALLATION.md](INSTALLATION.md).

Technique : une page HTML/CSS/JavaScript sans installation ; données et comptes dans Firebase
(SDK Firebase, licence Apache 2.0, inclus dans `vendor/`). Fonctionne hors connexion une fois installé.
